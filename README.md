# Medicare Fee Schedules Automation

Python utility for downloading, parsing, and consolidating Medicare fee schedule data published by the Centers for Medicare & Medicaid Services (CMS).

## What is included

- `medicare_fee_schedules.py` - downloads CMS releases, extracts schedule files, and writes consolidated CSVs.
- `requirements.txt` - Python dependencies.
- `output/` - CSV snapshots generated by the utility:
  - `CLFS_fee_schedule.csv`
  - `DMEPOS_fee_schedule.csv`
  - `Physician_NonQP_fee_schedule.csv`

The CSVs are snapshots and may not reflect the latest CMS releases. Run the utility to retrieve and process current releases.

## Requirements

- Python 3.9 or later
- Internet access to the CMS website

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Run

```powershell
python medicare_fee_schedules.py
```

When prompted, enter one of the approved CMS schedule URLs printed by the program. The utility downloads the selected schedule's available releases, processes the files, and writes the consolidated CSV under `output/`. Downloaded source files and processing caches are kept in `downloaded_files/` and `cache/`; these local working directories are not tracked by Git.

## Data sources

- [Clinical Laboratory Fee Schedule (CLFS)](https://www.cms.gov/medicare/payment/fee-schedules/clinical-laboratory-fee-schedule-clfs/files)
- [Physician Fee Schedule](https://www.cms.gov/medicare/payment/fee-schedules/physician/national-payment-amount-file)
- [Durable Medical Equipment, Prosthetics, Orthotics, and Supplies (DMEPOS) Fee Schedule](https://www.cms.gov/medicare/payment/fee-schedules/dmepos/dmepos-fee-schedule)

CMS publishes the underlying data. Refer to CMS for the authoritative and most current schedules. This project is not affiliated with or endorsed by CMS.
